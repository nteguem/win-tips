GEMINI — configuration explicite, aucun appel à l'import Python

WINTIPS_EDITORIAL_TRANSLATOR=gemini
WINTIPS_EDITORIAL_GEMINI_MODEL=gemini-3.5-flash-lite
WINTIPS_EDITORIAL_GEMINI_KEY=<secret dans l'environnement privé seulement>

La factory accepte aussi GEMINI_API_KEY, puis GOOGLE_API_KEY si la clé dédiée
est absente. Aucune recherche de fichier contenant une clé, aucun secret dans
Git, les URL, les caches ou les audits. Une clé absente bloque la traduction.
Le choix Gemini ne démarre aucun modèle local, même si MANAGE_MODEL=true.
Azure, Marian/Qwen et Ollama restent disponibles par sélection explicite.

REST generateContent, sortie structurée {translations:[{id,text}]}, une seule
candidate STOP. Pas de recherche web, outil, SDK supplémentaire ou repli cloud
automatique. Chaque fragment est un paragraphe complet ou un champ du contenu.
Les noms connus et valeurs numériques sont protégés dans des spans HTML ; leur
contenu, multiplicité, attributs et présence sont vérifiés avant retrait du HTML.
Les marchés restent déterministes. Aucune garde d'ordre lexical de LLM local.
Un lot incomplet ou un fait protégé modifié ne devient jamais publiable.
La validation de complétude anglaise et les validations API restent obligatoires.
Ces contrôles ne prouvent pas la fidélité sémantique : qualifier les vraies sorties.

Limites par défaut : délai requête45s, délai global180s pour la factory directe
(runner : au plus600s et le budget CLI demandé), 12requêtes physiques maximum,
12fragments/12000unités UTF-16 HTML par lot, sortie8192tokens maximum.
429/500/502/503/504 seulement : deux reprises maximum avec quota à chaque essai.
Retry-After entier respecté dans la limite du budget ; sinon arrêt sans reprise.
Toute autre erreur, réponse tronquée, JSON ambigu ou ID incorrect ferme le lot.

WINTIPS_EDITORIAL_GEMINI_DAILY_CHARACTERS=1000000
WINTIPS_EDITORIAL_GEMINI_MONTHLY_CHARACTERS=10000000
WINTIPS_EDITORIAL_GEMINI_QUOTA_DIR=/var/lib/wintips-editorial-worker/gemini-quota
Ce sont des garde-fous locaux d'entrée UTF-16, prompt et schéma inclus, avec
réservation durable/verrou exclusif avant chaque tentative même en échec. Ce ne
sont ni des quotas Google contractuels, ni une estimation du coût en tokens.
Le quota doit rester dans un répertoire durable privé partagé par les exécutions.

Caches privés distincts : translation-cache/gemini/{responses,native}.
Identité : provider/modèle/endpoint/consigne/options/source/ancrages/contexte FR.
Toute réponse réutilisée est revalidée. Les drapeaux passed anciens ne sont pas
une preuve. Les audits cloud gardent les tentatives et l'usage Google retourné.
Les refus sont dans translation-audits/EDITION/SOURCE.failed.json, avec motifs,
candidats et contexte disponibles, sans texte d'exception réseau ni clé.

Documentation primaire consultée le24octobre2026 :
https://ai.google.dev/api/generate-content

Tests : python -B -m unittest discover -s tests -p test_gemini_translation.py -v
Les transports sont simulés : ces tests ne prouvent ni clé, ni quota réel, ni
qualité linguistique native. Aucun déploiement/armement n'est déclenché ici.
